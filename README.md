# Java & Web Development Projects

This repository contains projects I developed while learning and applying **Java, Web Development, Databases, and Networking concepts**.

The projects demonstrate practical knowledge of **Java programming, client-server communication, GUI development, HTML, CSS, PHP, and SQL**.

---

## 📁 Projects

### 1. Java Server-Client Communication

A Java-based client-server application that demonstrates how multiple clients can communicate with a server over a network.

**Technologies:**

* Java
* Socket Programming
* TCP/IP
* Multithreading
* DataInputStream / DataOutputStream

**Key Concepts:**

* Client-server architecture
* Server socket and client socket
* Establishing network connections
* Handling multiple clients
* Sending and receiving messages

---

### 2. EMI Calculator

A Java-based desktop application for calculating loan EMI and displaying the complete payment breakdown.

**Technologies:**

* Java
* Java Swing
* JTable
* GUI Development

**Features:**

* EMI calculation
* Loan amount and interest calculation
* Monthly payment breakdown
* Interest and principal separation
* Remaining loan amount display

---

### 3. Web Project

A web-based project developed to practice frontend development, server-side programming, and database integration.

**Technologies:**

* HTML
* CSS
* PHP
* MySQL / SQL

**Key Concepts:**

* Web page structure and styling
* Form handling
* PHP server-side processing
* Database connectivity
* SQL queries
* CRUD operations
